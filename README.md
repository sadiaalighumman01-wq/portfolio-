## 📸 Adding Your Own Photo (Optional)

If you'd like to replace the initials avatar with your real photograph:
1. Save your photograph inside this folder (e.g., `profile.jpg`).
2. Open `index.html` and look for `<div class="relative mx-auto w-36 h-36 rounded-full...`.
3. Replace the inner `SI` text container with:
   ```html
   <img src="profile.jpg" alt="Sadia Ihsan" class="w-full h-full rounded-full object-cover">
   ```
